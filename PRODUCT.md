# FAMLY-Office

**What:** Sovereign Wealth Management OS — a private, self-hosted wealth dashboard for tracking assets, transactions, liabilities, insurance, documents, and crypto holdings with AI-assisted insights.

**Who:** High-net-worth individuals and family offices who need a single pane of glass for their financial life. Privacy-first: self-hosted, no third-party data sharing.

**Why:** Existing wealth management tools are either bank-locked (no cross-institution view) or SaaS (data leaves the premises). FAMLY-Office is a local-first React/Vite SPA + Express API that keeps everything on the user's own infrastructure.

**Register:** Product (dashboard/app UI, not marketing).

**Brand personality:** Calm authority. Private banking feel — restrained palette, precise typography, no visual noise. Trust is the product.

**Tech stack:** React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui, framer-motion, wouter (routing), Express.js API, MongoDB (Mongoose), pnpm workspaces.

**Key surfaces:** Dashboard, Transactions, Assets, Entities, Vault (document storage), Crypto, AI Panel (chat + insights), Onboarding tour, Settings/customization.

**Mobile standard:** MOBILE-UI-STANDARD.md at repo root — ≥44px tap targets, stacked card tables on mobile, safe-area insets, Playwright verification loop on live Vercel URL.

**Anti-patterns to avoid:** Gradient text, glassmorphism defaults, hero-metric templates, identical card grids, cream/sand/beige AI-default backgrounds, numbered section markers as scaffolding.
